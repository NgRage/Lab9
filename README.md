# Фролов Дмитрий КМБ Лабораторная №9


# Задание 1

## Задача 1

### Текст задачи
Реализовать приложение из ЛАБОРАТОРНОЙ РАБОТЫ №6 ЗАДАНИЯ 2 и 3 (Перегрузка операций) в 
виде WPF-приложения с графическим интерфейсом. Все требования к функционалу сохраняются.
Предусмотреть обработку возможных ошибок при работе программы
### Алгоритм решения
Решение задачи разделено на два уровня: логический и интерфейсный.

1. Класс логики:
Создан класс LineSegment. Для обеспечения инкапсуляции поля x и y объявлены как
private, доступ к ним осуществляется через публичные свойства.
Реализованы конструкторы: по умолчанию (создает нулевой отрезок) и с параметрами.
Методы и операторы реализованы как статические функции и
обычные методы. В операторе < используется логика сравнения числа с минимальным
и максимальным значениями границ (Math.Min и Math.Max), что позволяет корректно
обрабатывать отрезки, заданные как [5; 1], так и [1; 5].
2. Графический интерфейс:
Использован контейнер Grid для разделения окна на две функциональные зоны:
панель управления (слева) и панель вывода результатов (справа).
Для ввода координат и чисел для проверки применены элементы TextBox с
соответствующими метками TextBlock.
Вывод данных осуществляется в TextBlock
3. Логика взаимодействия(MainWindows):
Все обработчики событий обернуты в блоки try-catch. Это предотвращает
аварийное завершение программы при вводе букв вместо цифр или пустых строк.
При успешном выполнении операции результат форматируется в строку и добавляется
в лог.
Добавлена проверка на инициализацию объекта: операции не выполняются, пока
пользователь не нажмет кнопку «Создать отрезок».
